Super Streaming: Low-latency Pub/Sub System

SSI Securities Corporation · Internship project · June–August 2024

I built a multithreaded, MQTT v5-inspired pub/sub system in Rust and Tokio for streaming stock data from two exchanges. It reached sub-millisecond end-to-end latency with 1,000 clients, under 30 ms with 10,000 clients, and throughput of up to 500,000 messages per second.

Rust · Tokio · MQTT · Multithreading

iAgent: AI-Driven Project Assistance Tool

SSI Securities Corporation · Internship project · April–June 2024

I built a full-stack application for AI-assisted project planning and document workflows, with a FastAPI backend, React frontend, PostgreSQL, and a PGVector store. Its RAG workflow uses OpenAI embeddings to generate project requirements, test cases, and market research outputs.

FastAPI · SQLAlchemy · React · PostgreSQL · PGVector · TailwindCSS · OAuth 2.0
